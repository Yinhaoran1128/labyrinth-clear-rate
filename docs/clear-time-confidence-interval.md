# 1.8.0 预计通关时间置信区间

点估计保持为 **全部已完成对局耗时 / 成功次数**。这里估计的是包含失败重试成本的平均通关耗时，不是单次战斗耗时的分位数，也不是“下一次通关会落在哪个时间范围”的预测区间。

## 算法与输入

混合胜负样本使用配对均值比的近似双侧 95% Fieller 区间，参考 [NIST 的 Ratio of Means Confidence Interval](https://itl.nist.gov/div898/software/dataplot/refman1/auxillar/ratimean.htm)。每局数据为 `(T, I)`：T 是本局秒数，I 是成功指示（0/1）。成功、死亡和严格 120 秒超时均保留在同一个真实 N 场样本中，同归于尽只记成功。

设 n 为完成场数，k 为成功数，m=总耗时/n，p=k/n。目标为 m/p，即现有点估计。优先使用 Rust 已输出的稳定在线统计：

- M2 = `durationM2SecondsSquared`，耗时的中心平方和。
- C = `durationSuccessComomentSeconds`，耗时与成功指示的中心积和。
- 成功指示的中心平方和为 n·p·(1−p)。

样本均值的方差、协方差分别为：

```
vTT = M2 / [n(n−1)]
vII = n·p·(1−p) / [n(n−1)]
vTI = C / [n(n−1)]
```

若旧导出只提供原始矩，可用 `durationSquaredSeconds − totalSpentSeconds²/n` 和 `successSpentSeconds − totalSpentSeconds·p` 恢复 M2、C；当前运行优先使用 Welford 字段，避免大数相减。字段缺失或明显无效时不生成区间。

取 q 为自由度 n−1 的 t 分布 97.5% 分位数的平方，求非负 r 满足：

```
(p² − q·vII)·r² − 2(m·p − q·vTI)·r + (m² − q·vTT) ≤ 0
```

小自由度使用临界值表，大自由度使用逆 t 展开至四阶；已用独立 Python 标准库数值积分检查自由度 1、2、3、10、30、31、99、2999 的累积概率接近 0.975。判别式使用展开后的方差形式，二次根使用稳定解法，避免大均值或近重根时的精度损失。

## 退化情况

| 状态 | 返回与显示 |
|---|---|
| `bounded` | 有限上下界，单位秒；下界限制为非负 |
| `unbounded` | 上界为 ∞；若 Fieller 集合不连通，显示其非负范围的保守包络，可能为 0–∞ |
| `no_success` | 点估计继续为 ∞，区间显示“无法估计（无成功对局）” |
| `insufficient` | 只有一场时无法估计抽样方差，明确显示样本不足 |
| `missing_statistics` / `invalid_statistics` | 显示统计不足或无效，不把缺失数据当作零宽区间 |

全成功时样本成功指示方差为零，直接套用 Fieller 会忽略尚未观测到的失败，甚至给出零宽区间。因此改用保守联合界：利用严格截止给出的 `0≤T≤120`，取耗时均值的双侧 Hoeffding 界和全胜时成功率的精确单侧二项下界，各分配 0.025 的错误概率：

```
radius = 120 · sqrt(log(80)/(2n))
muLower = max(0, m − radius)
muUpper = min(120, m + radius)
pLower = 0.025^(1/n)
interval = [muLower, muUpper/pLower]
```

[Hoeffding 的有界随机变量原论文](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830)给出均值偏差界；全胜概率为 pⁿ，可直接反演二项下界。联合界不要求同一局的耗时与成功指示独立；仍要求局与局独立同分布。该边界方法有意偏宽，即使全胜且耗时相同也保留不确定性。均值超出120秒的数据视为无效；只有一场仍显示样本不足。混合胜负继续使用上述近似 Fieller 方法，不宣称整个混合策略具有严格有限样本覆盖率。

稀少成功不能支持有限上界时，保留 ∞，不会强行压成对称有限区间。

结果字段 `clearTimeInterval` 同时保留在 Worker 结果、计算器顶层结果及 `combatMeta` 中，包含 `confidenceLevel=.95`、`method="fieller-t"`（全胜为 `"hoeffding-binomial"`）、`approximate=true`、`status`、`lower`、`upper`；上下界单位为秒，不可用时为 null。1.8.1 推荐使用累计样本重新计算区间，图表和记录表每级仅显示累计场数最多的最新结果。

## 显示位置

- 普通战斗格子的悬浮详情显示通关耗时近似 95% 区间。
- 自动化胜率/耗时结果表显示区间，推荐等级悬浮详情也显示对应原始结果区间。
- 战斗耗时图的摘要卡、采样点详情、无障碍标签、全部记录表和误差棒显示耗时区间。上界为 ∞ 或超出纵轴时用上箭头标示，详情保留实际上下界。
- 胜率图继续使用 Wilson 区间。生活及强化房间为确定性公式，不增加模拟区间。

推荐的最近目标/平局选择规则、PAVA 拟合、严格 120 秒截止、真实 N 场和预计通关时间点估计均未改变。1.8.1 将 300 → 1000 → 3000 改为累计场数，批次内连续 RNG，批次间用不同的可复现种子独立运行；缓存签名为 `rust-completed-battles-v6-progressive-<WASM SHA-256>`。

合并批次 A/B 时，`n=nA+nB`、`w=nA*nB/n`、`dT=meanTB-meanTA`、`dI=pB-pA`。中心平方和为 `M2A+M2B+dT²*w`，中心积和为 `coA+coB+dT*dI*w`，避免原始矩相减造成的精度损失。计数及耗时原始矩相加，再用累计统计重算点估计与区间；不平均批次区间或通关耗时比值。

## 解释限制

Fieller 的精确结论依赖配对二元正态模型。这里成功指示是二项变量，使用样本均值近似，因此界面明确标注“近似 95%”。对局按独立同分布近似；极少成功或小样本时覆盖率不保证。区间是原始固定场数模拟的逐点区间，不是 PAVA 拟合置信带，也没有对自适应等级搜索、推荐后的选择或多重比较作校正。

本次只在 JS 中使用已有 Rust/WASM 统计量，引擎源码和实际 WASM 二进制未改变；已重新生成安装脚本。

# 1.7.2 真实完成场数与源码核对

日期：2026-10-17。计算器只使用内置 Rust/WASM，版本 1.7.2。未提交或推送；未修改独立仓库外的工作，也保留未跟踪的 1.6.0 文本文件。

## 事件循环和局间状态

- `Sim::new` 只初始化一次 RNG、玩家、能力/怪物模板缓存；每次 Worker 初始化只解析一次整套游戏数据。局间不重建 Worker 或 WASM，不重复设种子。
- `labyrinthTrials=N` 让事件循环以 `completed_trials < N` 为条件。局末完成胜负、死亡、超时判断和统计后计数；只有未达到 N 时才安排同一时刻的 `CombatStart`。第 N 场不安排第 N+1 场。
- 每局玩家用 `reset(0, rng)` 清除临时增益、控制及到期时间，保留永久增益与升级，重置技能/食饮冷却、恢复满血满蓝；候选增益序号也重置。怪物从模板新建并重置，固定半冷却仍扣除 haste 后计算。初始随机冷却的 RNG 抽取仍保留，然后覆盖为固定半冷却，避免改变后续随机序列。
- 局末清空队列，旧 DOT、持续恢复、增益到期、控制、施法、普攻、冷却等待和怒气事件不跨局；下一局重新安排恢复和怒气。普攻按攻击速度修正后的间隔安排，技能按施法速度修正后的施法时长安排。无刷新或复活等待。
- 发现并修正 `out_of_mana` 未显式清零的遗漏：它也是致盲等待时的调度标志，上一局遗留会影响恢复事件插入及后续事件顺序。新场数模式在恢复后清零并关闭上一局的缺蓝计时。旧时间模式保留原行为，供独立比较工具核对基准；新旧差异不能全部归因于样本量。

## 全局绝对时间核对

引擎保留连续推进的全局事件时间，避免更换时钟改变事件排序或规则。已检查：

| 路径 | 时钟与重置 |
|---|---|
| 技能、食饮冷却 | 比较 `last_used + cooldown` 与当前事件时间；玩家回到 MIN_SAFE_INTEGER，怪物半冷却相对新局开始时刻 |
| 持续增益、DOT、控制 | 起点/到期时刻相对当前事件时间安排；队列与临时状态在局末清除 |
| 恢复 | 每局从开始时刻 + REGEN_TICK 重新安排；缺蓝标志显式重置 |
| 怒气、超时 | 相对本局 `enrage_begin` / `encounter_start`；均在开局重设 |
| 触发器 | 当前血蓝、缺失血蓝、当前存活单位、增益和控制状态；未发现按全局累计时长变化的触发条件 |
| 经验、消耗与存活时间 | 累计结果指标，不用于玩家升级或下一局战斗参数；保留累计输出 |
| Ripple | 保留原 `truthy(last_used)` 判定。公开测试数据中可装备的普通技能均为正施法时长；零时长 blaze/bloom 为附加效果。对人为构造的零时长技能，绝对时刻 0 仍可能触及原判定边界，未擅自修改其规则 |

因此本次核对支持当前游戏输入下的局间重置与场数控制；不对任意未来能力或人为零间隔输入宣称严格独立同分布。共享 RNG 持续推进，固定种子复现整次任务，不代表逐场重复同一随机流。事件队列仍按微秒取整；最多 3000 场的累计时刻远低于双精度整数精度边界。

1.7.2 起，每局严格 120 秒截止。`process_next_event` 在执行前检查下一事件时间，处理完全部 ≤本局开始+120 秒的事件（含新加入的同时间事件），再在下一事件越界或队列为空时终结超时。恰好截止时刻的成功/死亡按原战斗事件顺序判定；更晚事件不执行、不消耗 RNG。超时总耗时加 120 秒、平方和加 14400 秒²；成功耗时总和不包含超时。独立旧版对比工具显式保留旧事件后检查方式，真实场数模式始终严格截止。

## 真实场数与同归于尽

`trials` / `completedTrials` 为真实完成场数，用于输入、停止和进度。互斥终结计数为 successes + terminalDeaths + terminalTimeouts = N。原生 `labyrinthStats.failedByDeath/failedByTimeout` 也是互斥分类。

1.7.1 按最新要求，同归于尽只算成功，不算死亡失败。计算器直接使用 Rust 互斥终结分类，胜率、PAVA 与 Wilson 分母均为真实完成场数；`statisticalTrials` 是完成场数的等值字段。原始 `deaths` 只保留为引擎诊断信息，不再用于推导计算器失败数。独立旧版对比工具仍保留原版比较口径。

预计通关时间始终为全部完成对局耗时 / 成功数，零成功为 ∞；新增 Kahan 总耗时、耗时平方和、成功耗时，以及 Welford 中心平方和/耗时与成功的中心积和均按真实对局记录。单位、样本方差和协方差换算见 `calculator/README.md`。统计字段保留到推荐历史记录及 JS 结果；未新增置信区间 UI。

对修改前的本地 WASM 与新产物运行 10 种怪物 × 等级 1/50 × 种子 1～20，共 **400** 组对照。新引擎的旧时间模式与修改前的事件数、胜利/死亡/超时、模拟时刻及最后成功时刻完全相同；累计完成耗时允许小于 0.1 ns 的浮点累计差。
